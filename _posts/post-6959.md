در این مطلب می‌خواهم به شما آموزش بدهم که LEMP را روی هر توزیع لینوکسی (اینجا دبیان) به راحتی انجام بدهید و از مزایای آن استفاده کنید. حتماً می‌دانید که LEMP سرواژه چه عبارتی است. اما برای کسانی که نمی‌دانند خلاصه بگویم که LEMP‌ عبارتی است که نشان می‌دهید ما یک لینوکس(Linux) داریم که روی آن نرم‌افزارهای Nginx، Mysql و PHP را نصب کرده‌ایم. ترکیب این چهار نرم‌افزار برای راه‌اندازی وبسایت‌های مبتنی بر PHP کافی است. مثلاً سیستم مدیریت محتوای وردپرس که پراستفاده‌ترین سیستم مدیریت محتوای در کل اینترنت است از PHP‌ استفاده می‌کند و با LEMP می‌توانیم به راحتی روی ضعیف‌ترین سخت‌افزارها هم تجربه خوبی از سرعت و امنیت و سهولت استفاده را تجربه کرد. پس برویم برای نصب LEMP روی دبیان

## پیش‌نیازهای نصب

1.  یک سرور لینوکسی با حداقل یک هسته و 512 مگابایت رم (هر چه مقدار رم و تعداد هسته‌ها بالاتر باشد عملکرد سرور بهتر خواهد بود)
2.  دسترسی root یا کاربر sudo (ما فرض می‌کنیم که شما دسترسی روت دارید و تمام دستورات را با دسترسی روت نصب می‌کنیم ولی برای نصب LEMP روی دبیان کاربر غیر روت با دسترسی sudo هم می‌تواند تمام این دستورات را اجرا کند)

## مرحله اول: نصب Nginx

در مرحله اول نصب LEMP روی دبیان باید وب‌سرور nginx را نصب کنیم. قبل از هر کاری ابتدا سرور خود را آپدیت می‌کنیم. هر جا از ما تایید خواست با حرف y تایید را انجام می‌دهیم.

```
apt update
apt upgrade
```

حالا برای نصب nginx دستور زیر را می‌زنیم

```
apt install nginx
```

به همین راحتی. nginx تنظیم شده است که بعد از نصب به صورت اتوماتیک اجرا شود و هر وقت که سرور ریستارت شد هم دوباره اجرا شود ولی برای اطمینان می‌توانیم دستورات زیر را بزنیم.

```
systemctl start nginx
systemctl enable nginx
```

دستور اول برای آغاز به کار و دستور دوم برای آغاز به کار nginx بعد از ریستارت شدن سرور است.

حالا باید فایروال را نصب کنیم. در برخی نسخه‌های دبیان فایروال ufw به صورت پیش‌فرض نصب شده است و در بعضی دیگر ما خودمان باید آن را نصب کنیم. برای نصب ufw باید دستور زیر را بزنید.

```
apt install ufw
```

بعد از اینکه ufw نصب شد دستور زیر را وارد می‌کنیم تا بعضی از آنها را در فایروال در لیست سفید قرار بدهیم.

```
ufw app list
```

از لیستی که نمایش داده شد گزینه Nginx Full و OpenSSH را انتخاب می‌کنیم تا بعداً دچار مشکل نشویم. برای این کار دستورات زیر را باید بزنیم.

```
ufw allow 'Nginx Full'
ufw allow 'OpenSSH'
```

با این کار ما انتقال اطلاعات از طریق پورتهای ۸۰، ۴۴۳ , 22 را مجاز کردیم. در این مرحله باید این فایروال را فعال کنیم. برای فعال کردن فایروال دستور زیر را می‌زنیم.

```
ufw enable
```

اگر در این مرحله در مرورگر خودمان آی‌پی سرور را وارد کنیم تصویر زیر را خواهیم دید که نشان می‌دهد کار ما به درستی انجام شده است.  
اما ما در اینجا از پروتکل http استفاده کردیم. اگر بخواهیم از https استفاده کنیم چکار باید کنیم؟  
برای استفاده از https باید گواهینامه ssl نصب کنیم و بهترین گزینه موجود که رایگان هم هست Letsencrypt است. برای نصب Letsencrypt در دبیان باید با دستور زیر نرم‌افزار certbot را نصب کنیم.

```
apt install certbot python3-certbot-nginx
```

## مرحله دوم: نصب MariaDB

مرحله دوم نصب LEMP روی دبیان نصب MariaDB است. برای نصب MariaDB کافیست دستور زیر را اجرا کنید.

```
apt install mariadb-server
```

بعد از نصب، برای راه‌اندازی MariaDB می‌توانید اسکریپت زیر را اجرا کنید. اجرای آن اختیاری است ولی شدیداً توصیه می‌شود. این اسکریپت برای افزایش امنیت دیتابیس‌های روی سرور است.

```
mysql_secure_installation
```

در این مرحله اولین چیزی که از شما پرسیده می‌شود این است که پسوورد اکانت روت MariaDB را وارد کنید. که البته شما چون تازه این نرم‌افزار را نصب کرده‌اید قطعاً پسووردی برای آن تنظیم نشده است. در نتیجه چیزی وارد نکنید و فقط اینتر بزنید. به تمام سوالهای بعدی که از شما پرسیده می‌شود هم جواب Y یعنی بله بدهید. در بین همین سوالات یک رمز قوی هم برای اکانت root دیتابیس انتخاب کنید.

## مرحله سوم: نصب PHP

مرحله سوم نصب LEMP روی دبیان نصب PHP است. توجه داشته باشد که در حال حاضر و در زمان نوشتن این مطلب دبیان 11 نسخه 7.4 نرم‌افزار PHP را نصب می‌کند. اگر به نسخه‌های دیگر نیاز دارید می‌توانید روش نصب آن نسخه خاص را در گوگل پیدا کنید. برای نصب PHP دستور زیر را اجرا کنید.

```
apt install php-fpm php-mysql
```

البته بعداً هر اکستنشن خاصی از PHP را که بخواهید می‌توانید به راحتی نصب کنید.

## مرحله چهارم: اضافه کردن دامنه

مرحله آخر نصب LEMP روی دبیان اضافه کردن دامنه است. فرض کنیم که دامنه ما domain.ir است. باید پوشه مربوط به این دامنه را بسازیم.

```
mkdir /var/www/html/domain.ir
```

بعد از ساخت پوشه باید دسترسی وب‌سرور nginx را به آن بدهیم که بعداً وب‌سرور دسترسی داشته باشد. در حالت عادی وقتی از کاربر root استفاده می‌کنید نیازی به این مرحله نیست ولی اگر بعداً روی این دامنه بخواهید سیستم مدیریت محتوایی مثل وردپرس را نصب کنید با این کار امکان نصب و آپدیت قالب و پلاگین پیدا خواهید کرد.

```
chown -R www-data:www-data /var/www/domain.ir
```

حالا باید به nginx این دامنه جدید را معرفی کنیم. برای این کار دستور زیر را می‌زنیم.

```
nano /etc/nginx/sites-available/domain.ir
```

و داخل آن محتویات زیر را قرار می‌دهیم.

```
server {
    listen 80;
    listen [::]:80;

    root /var/www/html/domain.ir;
    index index.php index.html index.htm;

    server_name domain.ir www.domain.ir;
    client_max_body_size 100M
    
location / {
      try_files $uri $uri/ /index.php?$args;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
        fastcgi_read_timeout 600;
        send_timeout                600;

    }
}
```

با زدن دکمه کنترل و x فایل را ببندید. فراموش نکنید که با زدن y تغییرات را ذخیره کنید. این کد علاوه بر اینکه سایت شما را قابل مشاهده خواهد کرد بلکه برای سیستم وردپرس هم کاملاً مناسب است و لینک‌های داخلی وردپرس دچار مشکل نخواهد شد. ضمن اینکه زمان تایم‌آوت وب‌سرور هم افزایش داده شده است.
