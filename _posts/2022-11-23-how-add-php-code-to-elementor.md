در این آموزش ساده قصد داریم روش ساده‌ای برای اضافه کردن کد php به المنتور را معرفی کنیم. ممکن است شما در موارد نیازمند اضافه کردن کد php‌ به سایت خود باشید که آن را با المنتور ساخته‌اید. در این حالت چطور کد را اضافه می‌کنید؟‌ می‌دانید که وردپرس اجازه اضافه کردن کد php به صورت مستقیم را نمی‌دهد.  
المنتور هم به صورت طبیعی اجازه اضافه کردن کد html و جاوااسکریپت را می‌دهد اما در مورد php جواب منفی‌ است. المنتور اجازه نمی‌دهد که کد php را به آن اضافه کنیم. با ما همراه باشید تا اضافه کردن کد php به المنتور را برایتان توضیح بدهیم.

### اضافه کردن کد php به المنتور

برای اضافه کردن کد php به المنتور کافیست کد زیر را به انتهای فایل functions.php‌ اضافه کنید و فایل را ذخیره کنید.

```
// Shortcode to output custom PHP in Elementor
function wpc_elementor_shortcode( $atts ) {
echo "This is my custom PHP output in Elementor!";
}
add_shortcode( 'my_elementor_php_output', 'wpc_elementor_shortcode');
```

اگر بخواهید چند کد مختلف php را به المنتور اضافه کنید باید چند بار این عمل را تکرار کنید و نام فانکشن‌ها را به صورت مناسب برای هر مورد استفاده کنید. امکان استفاده از یک نام برای بیش از یک فانکشن وجود ندارد.

توجه کنید که در کد بالا کد php مورد نظر خود را جایگزین کنید. حالا شما کد کوتاهی دارید که می‌توانید از آن در المنتور یا خود وردپرس استفاده کنید. در المنتور المان کد کوتاه یا shortcode را انتخاب کنید و کدکوتاه خود را وارد کنید و آن المان را اضافه کنید. در کد بالا کد کوتاه ما این است:

```
[my_elementor_php_output]
```
